\chapter{Implementation}
\label{ch:implementation}

\section{Introduction}
This chapter narrates the realization of design artifacts in production-oriented source code. Implementation choices emphasize readability, modularity, and alignment with Flutter and Python community conventions.

\section{Flutter Client Architecture}
The client employs \texttt{MaterialApp} gated by \texttt{ProviderScope}. Startup sequence: \texttt{WidgetsFlutterBinding.ensureInitialized()}, Firebase initialization, splash screen (four-second animated progress), \texttt{authStateProvider} resolution, and routing to \texttt{HomeScreen} or \texttt{LoginScreen}.

\subsection{Riverpod State Management}
Riverpod providers decouple widgets from data sources. \texttt{StreamProvider} listens to Firebase auth and finance streams; \texttt{StateNotifierProvider} encapsulates update checks and market price refresh timers. Such patterns prevent unnecessary rebuilds of the large \texttt{HomeScreen} widget tree.

\subsection{Feature Modules}
Each feature under \texttt{lib/features/} owns presentation widgets and feature-specific providers. Cross-cutting recommendation logic remains in \texttt{data/repositories} to enable mock injection during unit tests.

\section{Firebase Integration}
Firebase Auth provides email/password identity. Cloud Firestore stores \texttt{users}, \texttt{farms}, \texttt{users/\{uid\}/finance/monthly}, and \texttt{ai\_knowledge\_base}. Realtime Database ingests sensor payloads at \texttt{devices/\{deviceId\}/sensors/\{sensorId\}}.

\section{Flask Rule Engine}
The \texttt{CropRecommendationEngine} maintains in-memory crop agronomic metadata. Scoring penalizes deviation from optimal temperature, humidity, and pH ranges, with additional season and state penalties. Endpoints expose JSON compatible with \texttt{RecommendationModel} deserialization on the client.

\section{FastAPI Machine Learning Service}
The ML microservice loads \texttt{model.pkl} at startup via FastAPI lifespan hooks. Pydantic validates inference requests; responses include calibrated confidence percentages from \texttt{predict\_proba}.

\section{Gemini RAG Implementation}
\texttt{GeminiRagService} retrieves up to ten knowledge documents, performs keyword overlap matching, concatenates relevant passages into the prompt, and streams tokens to \texttt{ChatScreen}.
