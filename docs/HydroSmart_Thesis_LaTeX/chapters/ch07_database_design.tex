\chapter{Database Design}
\label{ch:database}

\section{Introduction}
\HydroSmart{} employs a polyglot persistence strategy: Cloud Firestore for document-oriented profiles and finance, Firebase Realtime Database for high-frequency sensor streams, and local JSON assets for offline crop catalogs.

\section{Firestore Collections}
\subsection{Users}
Path: \texttt{users/\{uid\}}. Fields: \texttt{name}, \texttt{phone}, \texttt{state}, \texttt{language}, \texttt{accountType}, \texttt{kisanId}, timestamps.

\subsection{Farms}
Collection \texttt{farms}: \texttt{ownerId}, \texttt{name}, \texttt{areaSqm}, geolocation optional.

\subsection{Finance}
Sub-collection \texttt{users/\{uid\}/finance/monthly}: expense line items, \texttt{estimatedRevenue}, \texttt{lastUpdated}.

\subsection{Knowledge Base}
\texttt{ai\_knowledge\_base}: \texttt{content}, \texttt{keywords}, optional \texttt{title}.

\section{Realtime Database}
Sensor path \texttt{devices/\{deviceId\}/sensors/\{sensorId\}} stores \texttt{temperature}, \texttt{humidity}, \texttt{ph}, \texttt{timestamp}.

\section{CRUD Mapping}
Create operations dominate registration and farm setup; reads use snapshot streams; updates modify finance fields; deletes soft-delete crops in backend Firestore (\texttt{active:false}).
